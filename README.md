## ✨ Features

- **🎬 60 FPS Cinematic AI Video Stage:** Hypnotic ultra-smooth slow-motion video of hand-rolled saffron spaghettoni twirled and descending into rich San Marzano Makhani glaze.
- **🎵 Sacred Sitar Background Music:** Ambient sitar and tanpura soundtrack with interactive animated audio wave controls (`MUSIC ON / OFF`).
- **📖 Maha Bhoj Degustazione Menu:** 5-course signature Indo-Italian tasting menu with tableside saffron pasta twirling.
- **🛎️ Atithi Devo Bhava Reservations:** Interactive royal booking drawer with live tableside pasta service options and complimentary Kesari Cardamom Thandai Bellini.
- **📱 Pixel-Perfect Responsive Design:** Tailored for laptops, ultra-wide screens, tablets, and mobile smartphones.

## 🛠️ Tech Stack

- **Framework:** Vanilla JavaScript + HTML5 + CSS3 (Modern Glassmorphism & Cinema Lighting)
- **Bundler:** Vite
- **Icons:** Lucide Icons
- **Typography:** Cinzel & Cormorant Garamond

## 🚀 Local Development

```bash
# Clone the repository
git clone https://github.com/SukanyaGowda/Hotel_Veda.git

# Enter project directory
cd Hotel_Veda

# Install dependencies
npm install

# Start local dev server
npm run dev
```
